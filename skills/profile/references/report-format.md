# Форма отчёта (строго)

Отчёт выводится сразу после подсчёта; «Поправки к отчёту» (calibration.md) и три раздела аудита (audit.md) идут позже отдельными сообщениями. Выводить ровно в этом порядке, с этими заголовками. Не добавлять разделов, вступлений, эмодзи и заключений. Тексты строк брать из `interpretation.md`.

```
## Профиль продуктивности

### Фасеты
| Фасет | Среднее | Уровень | Что это значит для методов |
|---|---|---|---|
| Порядок (ORD) | 2.2 | low | <строка из «Что предсказывает»> |
| ... (все 8 фасетов в порядке ORD, SDI, ACH, DUT, DEL, ACT, STR, VAR) |

### Архетип: <Название>
<Одно предложение из столбца «Кто это» таблицы архетипов (не столбец «Условие»).>
<Модификаторы, если есть, по одному на строку, начиная с «+ ».>

### Подходит
- <ровно по правилу сборки из interpretation.md: первые пять методов после разбиения ячеек, дедупликации и удаления методов, попавших в оба списка>

### Не подходит
- <то же правило для столбца «Не подходит»; первые пять>

### Почему
<Абзац «Почему» вашего архетипа дословно из раздела «Архетипы: почему…» interpretation.md (часть до «Что случится, если пойти против»).>
<Затем для каждого фасета с уровнем high или low, в порядке ORD, SDI, ACH, DUT, DEL, ACT, STR, VAR, одна строка: «Фасет (уровень): » + столбец «Почему» из таблицы «Почему и что будет, если пойти против».>

### Если пойти против
<Часть «Что случится, если пойти против» из абзаца вашего архетипа дословно.>
<Затем для тех же фасетов в том же порядке одна строка: «Фасет (уровень): » + столбец «Если пойти против».>

### Ритм
<Одна строка «Ритм» из таблицы архетипов.>

### Что вы сказали / ### Что нашёл в файлах / ### Итоговые рекомендации   ← отдельным сообщением после отчёта и калибровки, только если участник согласился на шаг 3; форма в audit.md

### Оговорка
Это самоотчёт по невалидированному русскому переводу пунктов IPIP-NEO, пройденный один раз. Уровни low/mid/high — фиксированные границы по сумме баллов, а не популяционные нормы: нормированный тест (например, Big Five Aspects) расположит вас иначе, особенно вблизи середины. Это зеркало, а не диагноз: используйте как повод посмотреть на свою систему, а не как приговор.
```

Правила:
- Уровни печатать латиницей: low / mid / high. Среднее — с одним знаком после запятой.
- «Подходит» и «Не подходит»: разбивать ячейки на отдельные методы только по точкам с запятой (запятые внутри метода ничего не разделяют); порядок — строка архетипа, затем фасеты ORD, SDI, ACH, DUT, DEL, ACT, STR, VAR (только уровни high/low); повторы определять по главному существительному («единый список» = «единый список без просрочек», оставить первое); метод, оказавшийся в обоих списках, удалить из обоих; оставить первые пять в каждом.
- Оговорка появляется ровно один раз — в конце. Нигде раньше не писать «это не диагноз» и похожее.
- Разделы «Почему» и «Если пойти против» — только дословные тексты из таблиц; фасеты с уровнем mid в них не попадают.
- Никаких оценочных слов о личности участника («вы ленивый», «вы творческий»). Только методы.
