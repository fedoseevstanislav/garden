# Петля проверки

Правило одно: **автор не проверяет свою работу.** Проверяет другая модель — лучше другого семейства, как минимум другая. Другой модели не достать — скажите и остановитесь; молча проверять собой нельзя.

## Что нужно

- **Что сделано** — путь к результату или «то, что мы только что сделали».
- **Что просили** — `мини-тз.md`, если есть; иначе исходная просьба: сообщение, файл или слова участника дословно. Проверяющий не видит ваш чат — всё, что ему нужно, идёт в запрос текстом.
- **Раунды** — по умолчанию 3.

Проверить сам `мини-тз.md`: что сделано — файл, что просили — слова участника из интервью дословно.

## Раунд

1. Критерии `проверяет: скрипт` прогоните сами и вложите команду с выводом в запрос. Критерии `проверяет: я` покажите участнику отдельным списком — они на его проверке.
2. Запишите запрос в `review-запрос-<раунд>.md` по форме ниже. Со второго раунда добавьте в конец замечания прошлого раунда с пометкой «читать только после собственной оценки».
3. Вызовите проверяющего только на чтение:

```bash
codex exec -s read-only --skip-git-repo-check -o review-вердикт-1.md - < review-запрос-1.md   # из Claude Code
claude -p --model sonnet --tools Read,Glob,Grep < review-запрос-1.md > review-вердикт-1.md   # из Codex
```

Ни того ни другого нет — подзадача (subagent) с явно другой моделью и тем же текстом.

4. Покажите вердикт целиком. Чините только `НЕ ПРОШЁЛ`; замечания без привязки — отдельным списком участнику.
5. `ПРИНЯТО` — готово. Раунды кончились — покажите, что осталось, и остановитесь: молчаливой приёмки не бывает.

## Запрос проверяющему

```
Ты проверяющий, не автор. Найди, где это НЕПРАВИЛЬНО, — не улучшай, не переписывай, не предлагай формулировок.

Что просили: <мини-ТЗ или исходная просьба, дословно>
Что сделано: <пути к файлам; прочитай целиком>
Уже проверено скриптом: <команда и вывод, если есть>

Как судить: по критериям C1…Cn и запретам A1…An, если они есть. Если нет — по просьбе: сделано ли то, что просили, ничего ли не выдумано, нет ли лишнего сверх просьбы, не сломано ли то, что работало. Если сделанное — мини-ТЗ: следует ли каждый критерий из слов участника (уточнить его слова до да/нет — можно, добавить требование, которого он не говорил, — нет; ⚠️ — автор сам не уверен, проверь особенно), и какой вопрос не был задан, хотя меняет результат.

Ответ: первая строка ПРИНЯТО / ДОРАБОТАТЬ / ОТКЛОНИТЬ. Дальше по каждому C и A (без критериев — по каждой находке, с цитатой из просьбы): цитата-доказательство → ПРОШЁЛ / НЕ ПРОШЁЛ / НЕ МОГУ ПРОВЕРИТЬ. ПРОШЁЛ только с цитатой. Критерий «проверяет: я» не оценивай — НЕ МОГУ ПРОВЕРИТЬ, проверяет человек. Своих критериев не добавляй. В конце не больше пяти замечаний: где — что нарушено — C/A или фраза просьбы.
```

## Запреты

- Не проверять свою работу самому; не пересказывать вердикт своими словами.
- Не чинить то, что не привязано к находке.
- Не объявлять работу принятой без строки `ПРИНЯТО` от проверяющего.
- Не давать проверяющему право записи.
