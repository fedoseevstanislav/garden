## Как отвечать

Первая строка ответа — только вердикт, одним словом:

- `ПРИНЯТО` — все критерии `ПРОШЁЛ`, запреты не нарушены;
- `ДОРАБОТАТЬ` — есть `НЕ ПРОШЁЛ`, но замысел рабочий;
- `ОТКЛОНИТЬ` — сделано не то, что просили, или нарушен запрет.

Правило приёмки одно: `ПРИНЯТО` — когда все критерии с тегом `обязательный` получили `ПРОШЁЛ` и не нарушен ни один запрет `A`. Критерии `качество` отчитываются наравне со всеми, но приёмку не блокируют.

Дальше — по каждому `C1…Cn`, потом по каждому `A1…An`, в порядке нумерации:

```
C2 · <короткая формулировка>
Доказательство: «<точная цитата из результата или имя файла и строка>»
Вывод: ПРОШЁЛ | НЕ ПРОШЁЛ | НЕ МОГУ ПРОВЕРИТЬ
```

Правила по выводам:
- Идентификатор обязателен и берётся из мини-ТЗ. Не переименовывай и не перенумеровывай.
- `ПРОШЁЛ` ставится только при цитате, которая это подтверждает. Нет цитаты — не `ПРОШЁЛ`.
- Критерий с тегом `проверяет: скрипт` уже прогнан исполнителем: доказательство бери из раздела «Уже выполненные проверки» — цитируй вывод команды. Если вывода там нет — `НЕ МОГУ ПРОВЕРИТЬ`.
- Критерий с тегом `проверяет: я` ты не оцениваешь: вывод `НЕ МОГУ ПРОВЕРИТЬ`, доказательство — строка «проверяет человек». Это не провал. Такой критерий не бывает `обязательный`; если встретился — скажи об этом одной строкой в замечаниях.
- `НЕ МОГУ ПРОВЕРИТЬ` также ставится, когда критерий сформулирован непроверяемо (оценочно, «качественно», «удобно») или нужного файла нет. Это честный ответ, не отговорка.
- Запрет `A` нарушен → `НЕ ПРОШЁЛ` с цитатой места нарушения.
- Своих критериев не добавляй. Того, чего в списке нет, ты не проверяешь.

В конце — не больше пяти замечаний, каждое одной строкой:

```
<где: файл, раздел, строка> — <что нарушено> — <C2 или A1>
```

Каждое замечание обязано ссылаться на идентификатор `C` или `A`. Если замечаний больше пяти — оставь пять самых тяжёлых. Если ни одного — напиши «Замечаний нет».
